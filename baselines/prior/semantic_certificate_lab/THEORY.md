# 面向程序编辑的任务误差与成对效果证书

**版本：v0.1，2026-09-20。** 本文是可复核的最小理论与实验记录，不是已经获得新颖性确认的论文，也不是完整代码代理的性能报告。

## 0. 这次真正建立了什么

建立三个有限程序世界中的结果：

1. 当前程序任务损失的**带符号执行残差恒等式**及可靠区间；
2. 一次代码编辑前后任务损失差的**成对、上下文相关区间证书**；
3. 保留共同执行状态可以消去无关不确定性，并使差分证书比两个边际证书直接相减更紧。

没有建立：任意软件的通用正确性距离、自然语言意图的形式化正确性、任意程序上的廉价分析器、长程编辑策略的最优价值估计、真实 coding LLM 的 RL 样本效率增益。

**重要纠正：** 分析器的抽象解释误差、当前程序的任务错误、一次编辑的真实作用、编辑策略未来能否完成任务，是四个不同对象。

## 1. 闭合世界与可信边界

设输入集合 X 有限，输入分布 mu 已知、固定，并且在 X 上全支撑。程序是 n 个确定性、全定义、有限状态转移的顺序组合：

\[
P=F_{n-1}\circ\cdots\circ F_0,
\qquad z_0=\operatorname{init}(x),\quad z_{i+1}=F_i(z_i).
\]

允许把 x 保留为不可变状态。这里 i 表示**候选程序执行**的阶段，不是代码代理第几次编辑。

任务规范给出可机检的有界损失

\[
\ell(x,z_n)\in[0,1],\qquad
E(P)=\mathbb E_{x\sim\mu}[\ell(x,z_n)].
\]

本次实验使用 0/1 违反损失。因此 E 是固定输入分布下的任务违反率；由于有限且全支撑，E=0 当且仅当所有输入均满足该任务。E 小不等于任意输入都安全。任务规范、输入分布及损失函数不由被评估的编辑修改。

这不要求知道一份“正确程序”，只要求知道所检查的形式任务。实验生成时使用保类程序来植入缺陷，但分析器没有访问该未破坏程序。

若扩展到副作用，z 必须覆盖后续执行真正依赖的 heap、文件、权限、数据库、随机源等；只比较局部变量相等不足以应用本文的消去规则。有限循环可展开；无限循环与终止性没有包含在当前实现中。

## 2. 为什么抽象空间三角不等式不够

此前候选式

\[
E(P,S)\le d_A(\widehat B(P),S^\#)+\epsilon_A(P)
\]

通常并不成立。取 alpha 把所有具体行为映到同一个抽象值。则抽象失配为 0；抽象分析可以在这个贫乏域上完全精确，分析误差也为 0。但是正确程序与错误程序的任务损失仍可以分别为 0 与 1。

因此，EPL 所控制的“抽象解释不精确性”不能直接补回被抽象彻底遗忘的任务信息。要么证明任务充分性/具体化桥接不等式，要么直接在所有具体化行为上计算任务损失的上下界。本文采用后者。

在本文中，误差条明确处于**任务损失单位**，不是任意 abstract-domain distance。

## 3. 任务条件的反向语义

定义从执行边界 i 开始的真实后缀损失：

\[
V_n(x,z)=\ell(x,z),\qquad
V_i(x,z)=V_{i+1}(x,F_i(z)).
\]

它是当前候选程序后缀的具体语义，不是代码代理未来编辑策略的 value function。确定性程序中，V_i 是一个确切函数；初始输入上的期望才形成违反率。

精确计算 V 可能很贵。取任意辅助函数 q_i(x,z)，但固定终端条件 q_n=ell。定义带符号的局部一致性残差：

\[
r_i(x,z)=q_{i+1}(x,F_i(z))-q_i(x,z).
\]

这才是一个定义完整的 execution residual。它不需要先随意定义 reachable set 与 required set 之间的距离。

## 4. 定理一：带符号残差的精确恒等式

对于每个具体输入 x，

\[
\ell(x,z_n)=q_0(x,z_0)+\sum_{i=0}^{n-1}r_i(x,z_i).
\tag{1}
\]

**证明。** 将每个 r_i 展开，所有内部 q_i 项望远镜消去，仅剩 q_n(x,z_n)-q_0(x,z_0)。使用 q_n=ell 即得。证毕。

令 d_i 是执行至边界 i 时 (x,z_i) 的实际占用分布，则

\[
E(P)=b+\sum_i\mathbb E_{d_i}[r_i],\qquad
b=\mathbb E_\mu[q_0(x,z_0)].
\tag{2}
\]

注意两点：

- r_i 有正有负。先取绝对值只能得到上界，会丢失补偿与方向信息。
- 如果为了精确求每个期望而完整执行所有输入，就已经付出了穷举成本。恒等式不是免费的 evaluator。

### 推论一：可靠残差区间

若在所有实际可达状态上存在可计算的

\[
\underline r_i(x,z)\le r_i(x,z)\le\overline r_i(x,z),
\]

则

\[
L=\max\{0,b+\sum_i\mathbb E_{d_i}\underline r_i\},\qquad
U=\min\{1,b+\sum_i\mathbb E_{d_i}\overline r_i\}
\]

满足 L <= E(P) <= U。证明是对逐点界取期望并代入 (2)。

也可以令 |r_i-hat r_i| <= epsilon_i，得到中心值

\[
\widehat E=b+\sum_i\mathbb E_{d_i}\widehat r_i
\]

及半径 sum_i E[epsilon_i]。这里 epsilon_i 必须是实际任务残差的可靠界。

若使用状态分区 C，已知 p_i(C)=Pr(z_i in C)，则可在每个 C 上取 min/max 后加权。本实验的占用质量由有限输入的精确前缀得到。若前缀分布也近似，则须再对所有允许的占用分布求可靠极值，不能把经验样本频率当成精确权重。

### 为什么这里没有强行写一串 kappa

q_i 及 V_i 已经包含后续程序和任务的影响。对于有合适度量的状态空间，可以另证

\[
|V_i(x,u)-V_i(x,v)|\le\omega_i(d(u,v)),
\]

或 Lipschitz 形式 kappa_i*d(u,v)。这能控制作用大小，但绝对值形式不能判断一次编辑到底变好还是变坏；对分支程序，界也可能很松。本文保留完整有符号的后缀作用，而不预设良性的全局 Lipschitz 常数。

## 5. 残差位置不是因果责任：一个不可忽略的反例

固定一个终端损失恒为 1 的三阶段程序。

- 选择 q=(1,1,1,1)，残差为 (0,0,0)，全部误差体现在 q_0。
- 选择 q=(0,0,0,1)，残差为 (0,0,1)，全部误差被放在最后一步。

两个分解都满足 (1)，程序完全相同。故“某一行残差很大”本身不能解释为“这一行导致了 bug”。数值或逻辑残差的定位仍依赖辅助表示。

要得到有定义的编辑 credit，必须规定一次真实干预，再分析该干预前后的同一任务。这引出下一定理。

## 6. 定理二：单次编辑的上下文相关效果

考虑只更改一个模块的两份程序：

\[
P=B\circ f\circ A,\qquad P'=B\circ f'\circ A.
\]

共同前缀 A、共同后缀 B、输入与任务均固定。定义编辑改善量

\[
I(P,P')=E(P)-E(P').
\]

正数表示改善，负数表示退步。记

\[
z=A(x),\qquad u=f(z),\quad v=f'(z),\qquad
V_B(x,y)=\ell(x,B(y)).
\]

则有精确恒等式

\[
I(P,P')=\mathbb E_\mu[V_B(x,u)-V_B(x,v)].
\tag{3}
\]

证明直接代入两份程序的定义。这里没有“别的代码变化”混入，只是定义明确的同输入反事实比较。

现在假设有后缀证书

\[
l_B(x,y)\le V_B(x,y)\le u_B(x,y).
\]

定义逐输入差分区间

\[
D_x=\begin{cases}
[0,0],&u=v,\\
[l_B(x,u)-u_B(x,v),\ u_B(x,u)-l_B(x,v)],&u\ne v.
\end{cases}
\tag{4}
\]

令 [L_D,U_D]=E_mu[D_x]（上下端点分别取期望），则

\[
\boxed{L_D\le I(P,P')\le U_D.}
\tag{5}
\]

**证明。** 不同状态时使用两个后缀逐点界相减；相同状态时同一个确定性后缀具有完全相同的任务损失，差值精确为零。逐输入成立后取期望。证毕。

因此：L_D>0 才足以认证改善；U_D<0 才足以认证退步；区间包含 0 时弃权。弃权不是断言“编辑无用”。

整个后缀并非只有末端输出：状态等同必须覆盖后续可观察的所有效应。同抽象 cell 不代表同具体状态，不能据此错误地消去。

## 7. 定理三：共同执行部分消除无关不确定性

令 w_B(x,y)=u_B(x,y)-l_B(x,y)，以及编辑影响集合 D={x: f(A(x)) != f'(A(x))}。

若不用相等状态消去，单独估两边的前缀条件边际误差再相减，区间宽度为

\[
W_{marg}=\mathbb E[w_B(x,u)+w_B(x,v)].
\]

成对证书的宽度恰为

\[
W_{pair}=\mathbb E[\mathbf1_D(x)(w_B(x,u)+w_B(x,v))]\le W_{marg}.
\tag{6}
\]

而且 D 外两个区间相同，其差区间关于 0 对称；把它替换成 [0,0] 不仅减小宽度，还使整个成对区间包含于边际差分区间。

若所有后缀证书宽度 <= w_max，则

\[
\boxed{W_{pair}\le2w_{max}\Pr_\mu(D).}
\tag{7}
\]

所以精度瓶颈可以依赖“编辑真正改变了多少可达输入/状态”，而不是整个程序的分析不确定性。这不保证快速算法，但说明了为什么 relational summaries / shared-state identity 是有意义的系统原语。

这与 relational verification 的已有基本思想相同。RelCost 已经明确利用两次执行的共享结构改善 execution-cost difference 的界。此处的不同目标量是固定任务损失差，不能把“比较两份程序”当成新发明。

## 8. 具体可实现的可靠分析器

实验状态 z in {0,...,63}，任务标签 t=x//16；ell(t,z)=1[z//16 != t]。使用大小 b in {16,8,4,2,1} 的连续分区 C，alpha_b(z)=z//b。

终端：

\[
l_n(t,C)=\min_{z\in C}\ell(t,z),\qquad
u_n(t,C)=\max_{z\in C}\ell(t,z).
\]

反向传播：

\[
l_i(t,C)=\min_{z\in C}l_{i+1}(t,\alpha_b(F_i(z))),
\]
\[
u_i(t,C)=\max_{z\in C}u_{i+1}(t,\alpha_b(F_i(z))).
\tag{8}
\]

**可靠性证明。** 终端由 min/max 定义成立。假设后缀界成立，则对任意 z in C，实际 V_i(t,z)=V_{i+1}(t,F_i(z)) 被对应后缀 cell 的上下界夹住；再对所有 z 取 min/max 即得到 (8)。逆向归纳到 i=0。

这是一个小型、显式有限域的抽象解释器，而不是 EPL 的完整实现。q 可以取 (l+u)/2，其任务语义误差半径为 (u-l)/2。运行时利用旧程序未更改的后缀表，为新编辑提供 (4)。

细分使用嵌套分区。由于转移像集合与 min/max 的单调性，更细分区不会使相应点值下界变小或上界变大，因此成对区间也不会扩张；实验逐对检查了这一点。

## 9. 上界下降不等于真实改善

即使分析器不更换，U_before > U_after 也只说明两个上界排序，不说明 E_before > E_after。

一个具有自然局部误差和界的反例：参考两个模块都为 identity；当前模块分别偏移 +1/4 和 -1/4，整体完全正确，局部范数和界为 1/2。只修第一模块后，整体误差为 1/4，局部和界也为 1/4。上界下降，但真实结果变坏。

本次随机程序中还找到了固定 b=8 的实际反例：

- 前：E=20/64，U=64/64；
- 后：E=22/64，U=56/64；
- 上界差宣称 +8/64 的“进展”，真实改善量是 -2/64；
- 成对证书给出精确区间 [-2/64,-2/64]。

另一个独立问题是只细化 analyzer 就能缩小 U。若程序没变，真实编辑作用应为 0；不能把分析器证明能力提高混同为修复程序。

## 10. 即使有精确 E，也不等于长程编辑价值

构造两个布尔代码参数 a,b；只允许一次翻转一个参数。程序输出

```
0, if a and b
1, if not a and not b
2, otherwise
```

任务要求输出 0，损失为 output/2。

|代码状态|精确任务误差|最少剩余编辑|
|---|---:|---:|
|00|0.5|2|
|10|1|1|
|01|1|1|
|11|0|0|

从 00 修复必须先升高任务误差。只允许被认证为即时改善的 edit，会把这个完全可解的问题堵死。

因此不能从本文推出 I(P,P') 等于 RL advantage，或者“证书变好”保证未来成功率上升。真实编辑策略的 value function 还依赖允许动作、未来预算、探索策略与可修复性结构。

若额外假设每个错误状态都存在降低 E 的允许编辑，并且找到这种编辑，才可推出下降式策略的进度保证。例如误差取 {0,1/N,...,1} 且每次降低至少 1/N 时，最多 N*E(P_0) 步到达 E=0；但本节反例说明该附加假设并不普遍成立。

## 11. 如何安全接入 RL

第一种用途是保留真实目标的 potential shaping，而不是只奖励局部改善：

\[
r'_t=r_t+\lambda[\gamma\Phi(s_{t+1})-\Phi(s_t)].
\]

状态 s_t 应包含当前程序、规范、分析器版本/状态及剩余预算等维持 Markov 性所需信息。Phi 必须固定为该完整状态的函数，且有界。对有限回合，所有终端状态（成功、失败、超时）统一令 Phi=0，则

\[
\sum_{t=0}^{T-1}\gamma^t(r'_t-r_t)=-\lambda\Phi(s_0).
\]

它不会改变固定初始状态下完整轨迹的回报排序。这是经典 potential-based shaping 的性质，不是本项目的新定理；更不保证有限样本下训练一定加速。

取 Phi=-U 可以提供启发式学习信号，但单步 shaping reward 仍不能称为“已证明的语义进展”。若只取 max(0,L_D) 累加并替换原任务奖励，一般也不保留原目标。

第二种用途是 pairwise supervision / candidate comparison：在 L_D>0 或 U_D<0 时给有证明含义的方向标签，不确定时允许进一步分析或继续探索。这里不要把“有 immediate-effect 标签”说成“完整 long-horizon credit 已解决”。

## 12. 新颖性与下一道真正的难题

EPL [R1] 的对象是抽象解释不精确性的传播；本文使用的简单界直接针对任务损失。定量 weakest-preexpectation 与 QSL [R2] 提供了成熟的前置理论。Relational cost analysis [R3] 已经说明为什么直接估两个程序的差比独立求界更精确。MDP verification 的上下界与按需探索 [R4]、potential shaping [R5] 也不是新想法。

因此，本次成果是一个**严谨、可执行的研究原型与排错结果**。值得继续检验的潜在系统贡献是：在精确验证已经昂贵的 closed code/runtime 世界中，利用语义切片、关系式摘要、增量失效及按需精化，在相同总预算下提供更多可靠编辑比较，并改善真实长程学习。当前有限查表程序尚未证明这种收益。
